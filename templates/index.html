1 · connect camera

Connect first so Tapo Enhance can read the camera’s available recording history. Credentials are encrypted immediately and never stored as plaintext.

For a battery-mode D225 with Camera Account disabled, use your Tapo account password. The app will try the compatible admin login automatically and use the same password for local media encryption.

2 · DVR Mode

DVR Mode downloads the selected camera history, then checks for new videos on the schedule you choose. The default is daily at 12:10am server time.

It never deletes videos from the camera. Local copies can follow the history window or be kept permanently.
